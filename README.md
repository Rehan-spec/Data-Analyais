🦠 SQL Exploratory Data Analysis on COVID‑19 Data

📌 Project Overview
This repository contains an Exploratory Data Analysis (EDA) project performed entirely in SQL on COVID‑19 datasets. The goal is to demonstrate how SQL can be used for:

• 	Data cleaning and transformation<br>
• 	categorize data in male , female , age group , states  <br>
• 	Aggregations using max , min , case when<br>
• 	Trend analysis of deaths and recovery <br>

The project highlights practical SQL techniques for analyzing real-world health data.
